# Future Apple CarPlay implementation

A Safari PWA cannot act as a native CarPlay navigation app. There is no CarPlay button in this web release.

A future implementation needs a native iOS application, Apple developer enrollment, the applicable CarPlay navigation entitlement and approval, native navigation templates, audio/session handling, location/background execution, and App Store review. A shared route/report API can be reused, but native UI, safety interactions, offline routing/map licensing and entitlement compliance need their own implementation and physical-car testing.

Do not budget this as free web-only development or claim CarPlay support until Apple approves the entitlement and a native app is tested. No enrollment, paid service or native project was created.
